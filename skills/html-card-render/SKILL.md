# HTML 카드 렌더 (html-card-render)

이미지 생성 모델에 글자를 맡기면 철자가 틀리거나 숫자가 뭉개지는 일이 많습니다. 그래서 글자와 숫자는 HTML로 정확하게 넣고, 그 HTML을 크롬으로 찍어 PNG로 만듭니다. 그림이 필요하면 그림만 따로 만들어 `<img>`로 넣습니다.

`chrome --screenshot --window-size=...`로 찍으면 창 테두리와 화면 배율 때문에 크기가 틀어지는 경우가 있습니다. 이 스킬은 크롬 개발자 프로토콜(CDP)로 화면 크기와 배율을 직접 지정하고, 저장한 PNG 머리 부분을 다시 읽어 실제 가로·세로가 맞는지 확인합니다.

## 준비
- Node 22 이상(내장 WebSocket을 씁니다). 따로 설치할 패키지는 없습니다.
- 크롬, 엣지, 크로미움 중 하나. 자동으로 찾지 못하면 `CHROME_PATH` 환경변수에 실행 파일 경로를 넣습니다.

## 사용
```bash
# 카드 여러 장: HTML 안의 .page 마다 한 장씩 out-01.png, out-02.png ... 로 저장합니다
node scripts/render.mjs templates/card-4x5.html out.png --size 1080x1350 --scale 2 --pages

# 배너 한 장
node scripts/render.mjs templates/banner.html banner.png --size 1280x400 --scale 2

# 결과를 JSON으로
node scripts/render.mjs card.html out.png --size 1080x1350 --scale 2 --pages --json
```
`--scale 2`이면 1080x1350 카드가 2160x2700 PNG로 나옵니다. 인스타그램 4:5 카드는 1080x1350, 유튜브 썸네일은 1280x720, 깃허브 배너는 1280x400을 많이 씁니다.

## 자동 검사
- **글자 넘침**: 찍기 전에 페이지 안에서 상자보다 넓거나 높아 잘리는 글자, 카드 바깥으로 튀어나온 요소를 찾아 목록으로 보여 줍니다. 검사에서 빼야 하는 장식 요소에는 `data-qa-ignore`를 붙입니다.
- **크기**: 저장한 PNG의 실제 크기가 `크기 x 배율`과 다르면 `SIZE`로 표시합니다.
- **깨진 그림**: 불러오지 못한 `<img>`를 알려 줍니다.
- 위 셋 중 하나라도 걸리면 종료 코드 1입니다. 브라우저를 못 찾거나 페이지 스크립트가 오류를 내면 종료 코드 2입니다.
- 글꼴(`document.fonts.ready`)과 그림이 다 불러와진 뒤에 찍습니다.

## 디자인 규칙 (템플릿 기준)
1. **카드 한 장에 메시지 하나만** 담습니다. 할 말이 많으면 장을 나눕니다.
2. 1080 너비 기준으로 **제목 48px 이상, 본문 28px 이상**으로 씁니다. 휴대폰에서 읽혀야 합니다.
3. **강조색은 하나만** 씁니다. 템플릿은 순백 바탕, 굵은 검은 테두리, 코발트 파랑(#2547F4) 한 가지이고, 막대그래프에서도 가장 중요한 값 하나만 강조색으로 칠합니다.
4. 베이지, 크림, 아이보리 같은 누런 바탕은 쓰지 않습니다.
5. 글자와 숫자는 HTML로 넣고, 그림 생성 모델에는 글자 없는 그림만 맡깁니다.
6. 실제 화면 캡처를 넣을 때는 내용을 고치지 않고, 계정명이나 개인정보가 보이면 잘라 냅니다.
7. 카드 아래쪽에 장 번호(1/3)를 넣어 순서를 알 수 있게 합니다.

## 마지막 확인 (필수)
자동 검사가 PASS여도 **만든 PNG를 직접 열어 눈으로 봅니다.** 검사는 상자 넘침만 잡을 수 있고, 글자끼리 겹치거나 그림이 글자를 가리는 것, 줄바꿈이 어색한 것은 사람이 봐야 압니다. 숫자가 원래 자료와 같은지도 대조합니다.

## 한계
- 템플릿의 Pretendard 글꼴은 인터넷(CDN)에서 받아 옵니다. 오프라인이면 맑은 고딕 같은 시스템 글꼴로 바뀌어 줄바꿈 위치가 달라질 수 있습니다.
- 넘침 검사는 `overflow: hidden`이나 `nowrap`처럼 잘리는 조건이 있는 요소를 기준으로 판단합니다. 그냥 다음 줄로 넘어가 레이아웃이 밀리는 경우는 카드 밖으로 튀어나올 때만 잡힙니다.
- 동영상, 애니메이션 중간 프레임은 찍지 않습니다. 정지된 화면만 다룹니다.
