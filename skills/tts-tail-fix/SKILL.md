# TTS 끝소리 끊김 고치기 (tts-tail-fix)

## 문제
보이스 클론 TTS(Qwen3-TTS 등)로 만든 음성은 마지막 음절이 말소리 크기 그대로 20~50ms 만에 끊기는 경우가 많습니다. 사람이 말할 때는 끝소리가 100ms 넘게 서서히 줄어들기 때문에, 이렇게 끊긴 음성은 듣는 사람에게 "말하다 만 느낌"을 줍니다. 작성자가 측정했을 때 보이스 클론 원본 12개 중 11개가 이렇게 끊겨 있었습니다.

효과가 **없었던** 방법도 적어 둡니다. 문장 끝에 " ..."을 붙여도 6개 모두 그대로 끊겼고, 끝 무음을 남긴 채 그 무음 구간에 페이드를 걸면 소리는 전혀 줄지 않습니다.

## 해결 순서
1. **버리는 단어(센티널)를 붙여 합성합니다.** 대본 문장 끝에 짧은 단어를 덧붙입니다(한국어는 ` 네.`). 모델은 진짜 문장을 자연스럽게 끝낸 뒤 0.2~0.5초 쉬고 "네"를 말하기 때문에, 진짜 문장의 끝소리는 온전히 남습니다.
2. **쉼에서 자릅니다.**
   ```bash
   python scripts/tts_tail.py cut raw.wav clean.wav
   ```
   0.2초 이상 조용한 구간 뒤에 소리가 0.08~0.45초만 남은 마지막 쉼을 찾아, 쉼이 시작되고 60ms 뒤에서 자르고 "네"는 버립니다. 이어서 끝 처리(4번)까지 합니다.
3. **쉼이 없으면 다시 합성합니다.** 종료 코드 3(`NO_PAUSE`)이 나오면 시드를 바꿔 최대 3번 다시 합성합니다.
4. **그래도 안 되면 끝만 다듬습니다.** 센티널 없이 합성한 파일에
   ```bash
   python scripts/tts_tail.py finish raw.wav clean.wav
   ```
   를 씁니다. 끝 무음을 -60dB 기준으로 잘라 내고, 소리가 **실제로 끝나는 지점**에 0.14초 코사인 페이드를 건 뒤 0.35초 무음을 붙입니다. 끝은 조금 짧아지지만 끊기지는 않습니다.
5. **검사합니다.**
   ```bash
   python scripts/tts_tail.py check clean.wav other.wav   # CHOPPED가 하나라도 있으면 종료 코드 1
   ```
6. **마지막 단어를 받아쓰기로 확인합니다.** Whisper 같은 음성 인식으로 클립 끝 단어가 대본의 마지막 단어와 같은지 봅니다. "네"가 남았거나 진짜 마지막 단어가 잘렸으면 다시 합성합니다.

준비: `pip install numpy soundfile`. 값은 `--silence-db -50 --min-pause 0.2 --fade 0.14 --pad 0.35`로 바꿀 수 있습니다. 숨소리가 큰 목소리는 -60dB로 낮추면 쉼을 놓치므로 -50dB를 기본으로 둡니다.

## 꼭 알아 둘 것
- `check`의 OK는 끝소리가 얼마나 빨리 줄어드는지만 잰 값입니다. 마지막 음절이 덜 발음된 문제는 잡지 못하므로, **직접 듣는 확인을 대신하지 못합니다.** 듣지 못했다면 듣지 못했다고 기록합니다.
- 센티널을 쓰면 클립마다 합성 시간이 최대 4배까지 늘어날 수 있습니다.
- 다른 사람의 목소리를 허락 없이 복제하지 않습니다. 이 스킬은 본인 목소리나 사용 허락을 받은 목소리에만 씁니다.
- 이미 공개한 음성·영상을 이 규칙만으로 다시 만들거나 다시 올리지 않습니다.
