# 유튜브 게시 완료 점검 (youtube-publish-checklist)

에이전트에게 업로드를 맡기면 영상 파일은 잘 올리는데, 쇼츠 썸네일이나 예약 공개 영상의 고정 댓글처럼 **업로드 뒤에 해야 하는 일**을 자주 빠뜨립니다. 작성자도 실제로 두 번 겪었습니다. 롱폼은 예약 공개라 비공개 동안 댓글을 달 수 없었고, 그 뒤에 이어서 달 사람이 없었습니다. 쇼츠는 다른 플랫폼에 올린 영상을 "그대로" 올리라는 말을 썸네일 생략으로 잘못 해석했습니다. 이 스킬은 영상마다 조건을 검사해서 다 통과하기 전에는 완료라고 말하지 못하게 합니다.

## 영상마다 확인할 것 (롱폼과 쇼츠를 따로)
1. **맞춤 썸네일**
   - 롱폼은 16:9, 1280x720 이상이고, 쇼츠는 9:16, 1080x1920을 권장합니다. 둘 다 2MB 이하 JPG/PNG여야 합니다.
     ```bash
     node scripts/publish-gate.mjs thumb thumb.jpg --kind long
     node scripts/publish-gate.mjs thumb short.jpg --kind short
     ```
   - 올린 뒤 Studio에서 '모든 변경사항이 저장되었습니다'를 보고, 채널 페이지(쇼츠는 Shorts 탭)를 새로고침해 썸네일이 실제로 보이는지 화면으로 확인합니다.
   - 하루 맞춤 썸네일 한도나 전화 인증 때문에 못 올리면 완료가 아니라 '막힘'으로 보고합니다.
2. **고정 댓글**
   - 즉시 공개라면 공개 직후 같은 작업 안에서 댓글을 달고 고정합니다.
   - 예약 공개라면 비공개 동안 댓글을 달 수 없으므로, **업로드를 끝내기 전에** 공개 5~10분 뒤에 실행되는 후속 작업(예약 작업, 알림, 캘린더)을 만들어 둡니다. "나중에 달겠다"만 적고 끝내지 않습니다.
   - 댓글은 영상 내용을 한 줄로 요약하거나 질문 하나로 씁니다. 겪지 않은 경험을 지어내지 않습니다.
   - 쇼츠도 `https://www.youtube.com/watch?v=<ID>`로 열면 일반 댓글 칸이 나옵니다. 고정한 직후에는 표시가 늦게 뜰 수 있으니, 새로고침하고 5~8초 기다린 뒤 "고정함" 표시를 확인합니다.
   - 아동용 영상(댓글 사용 불가)과 사용자가 고정 댓글을 빼라고 한 영상은 예외입니다.

## 묶음 검사
업로드한 영상들을 `publish.json`에 적고 검사합니다(형식은 스크립트 첫머리 주석 참고).
```bash
node scripts/publish-gate.mjs check publish.json
```
종료 코드 0이 나와야 사용자에게 "게시 완료"라고 보고합니다. 1이면 빠진 항목이 영상별로 나오므로 그것부터 처리합니다.

## 보고 형식
`롱폼 썸네일 ✓ / 롱폼 고정 댓글 ✓ / 쇼츠 썸네일 ✓ / 쇼츠 고정 댓글: 공개 뒤 후속 작업 예약됨(작업 이름)`

## 한계
- 스크립트는 파일 규격과, 사람이 확인했다고 적은 값을 검사할 뿐입니다. 채널 화면에 실제로 보이는지는 직접 보고 `thumbnailVerifiedOnChannel`, `pinnedVerified`를 채웁니다. 확인하지 않은 값을 true로 적지 않습니다.
- YouTube Data API는 댓글 고정 여부를 알려 주지 않기 때문에 고정 확인은 화면으로 해야 합니다.
